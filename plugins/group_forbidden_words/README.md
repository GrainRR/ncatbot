# group_forbidden_words

## 基本介绍

检测群消息中的违禁词；命中后提示并尝试撤回消息。群主和管理员可以维护词库。

## 获取方式

本插件仅随本项目 Release 分发。请下载与项目版本匹配的发布包，并按发布包附带的部署说明安装；无需单独克隆插件仓库。

## 前置依赖

- 运行环境：已完成 NcatBot、NapCat 和 QQ 初始化。
- 软件包：无额外 Python 软件包依赖。
- 其他插件：无。
- 配置与权限：无需密钥；需要授予机器人群管理和撤回消息权限。词库文件为 `plugins/group_forbidden_words/forbidden_words.txt`。

## 使用方式

群主或管理员可发送：

```text
#添加违禁词 <词>
#删除违禁词 <词>
#违禁词列表
```

添加测试词后，普通成员发送该词，机器人应提示并撤回消息。普通成员不能使用词库管理命令。
