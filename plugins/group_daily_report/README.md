# group_daily_report

## 基本介绍

根据已归档的群消息生成当天、昨天或指定日期的发言统计和排行。

## 获取方式

本插件仅随本项目 Release 分发。请下载与项目版本匹配的发布包，并按发布包附带的部署说明安装；无需单独克隆插件仓库。

## 前置依赖

- 运行环境：已完成 NcatBot、NapCat 和 QQ 初始化，且机器人能够读取群消息和成员信息。
- 软件包：无额外 Python 软件包依赖。
- 其他插件：必须先部署并加载 [message_archive](../message_archive/README.md) `>=0.1.0,<0.2.0`；目标群还需至少有一条已归档消息。
- 配置与权限：无必填配置或额外群管理权限。

## 使用方式

在已有归档消息的群中发送：

```text
#每日报表 今日
```

也可使用 `#每日报表`、`#每日报表 昨日` 或 `#每日报表 YYYY-MM-DD`。机器人会回复消息总数和发言排行。
