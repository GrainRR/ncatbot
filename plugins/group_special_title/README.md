# group_special_title

## 基本介绍

机器人是群主时，群成员可为自己申请专属头衔；管理员还可为被 @ 的群成员发放专属头衔。头衔最多 6 个汉字或 12 个半角字符。

## 获取方式

本插件仅随本项目 Release 分发。请下载与项目版本匹配的发布包，并按发布包附带的部署说明安装；无需单独克隆插件仓库。

## 前置依赖

- 运行环境：已完成 NcatBot、NapCat 和 QQ 初始化。
- 软件包：无额外 Python 软件包依赖。
- 其他插件：无。
- 配置与权限：无必填配置或密钥；机器人必须是群主。

## 使用方式

群成员可申请自己的头衔：

```text
#申请头衔 测试头衔
```

仅管理员可为他人发放头衔：

```text
#发放头衔 @成员 测试头衔
```

机器人回复成功后，在 QQ 群资料中查看新头衔。为成员发放时必须使用 QQ 的真实 @ 提及。
